# Отчёт о стоимости координации

В разделе **Расход** выберите запуск или цепочку, затем очередь и задачу.
Блок **Стоимость координации** показывает каждый выбранный запуск отдельно:
вызовы исполнителя, ревьюера и исправлений, токены по ролям, время и исходы.
Страницы списка запусков служат навигацией: отчёт строится по всем задачам
выбранного запуска, а цепочка загружается целиком, независимо от страницы списка.

## Значения и ограничения

- Подтверждённые вызовы считаются только по завершённым записям бюджета,
  прошедшим существующую проверку `assertExecutionBudgetEvidenceV1`.
  Резервирование без результата и неоднозначное восстановление не доказывают
  вызов. `not_started_after_reservation` даёт ноль вызовов и токенов.
- Число попыток берётся из записанных счётчиков. Оно не доказывает запуск
  процесса и показывается отдельно.
- `Нет данных` не равно нулю. `частично` означает сумму известных значений
  при неизвестной полноте. Отсутствующие, null, отрицательные, дробные и
  небезопасные целые значения не превращаются в ноль.
- В старом формате токены всегда частичные: полнота событий usage неизвестна.
  Роли сопоставляются точно, без обрезки пробелов. Все записи с одинаковыми
  ролью, попыткой и временем исключаются как неоднозначные дубликаты.
- Кэш-чтение не прибавляется повторно к входящим токенам. Денежной оценки нет.
- Длительность запуска и задачи требует обоих корректных временных значений.
  Незавершённый интервал не оценивается по текущему времени.
  Время резервирования включает подготовку и запись результата, а не только
  работу модели. При параллельности сумма интервалов может превышать время запуска.
- Перенесённый результат не переносит расход исходного запуска в текущий.
  Повреждённые бюджетные записи не заменяются менее строгой старой телеметрией.

Отчёт добавлен в существующий ответ `GET /api/runs/:id/metrics` как поле
`coordination`. Проекция не меняет данные и не читает промпты, логи, вывод
инструментов или содержимое исходников. Это информационное представление,
не доказательство качества, не разрешение на исполнение и не реализация
предложенного ранее отдельного офлайн CLI.
